# Logging Configuration: App Service

**Service**: Azure App Service (Linux Web App)
**Category**: Compute & Storage
**Last Updated**: 2026-03-27
**NIST 800-53**: AU-2, AU-3, AU-6, AU-12
**OMB M-21-31**: EL2 (Intermediate) for HTTP/platform logs, EL3 (Advanced) for audit logs

---

## Log Collection Architecture

App Service diagnostic logs are forwarded directly to the centralized Log Analytics workspace via Azure Monitor diagnostic settings. No agent installation is required — App Service is a PaaS service with built-in diagnostic log integration.

```
App Service → Diagnostic Settings → Log Analytics Workspace
```

---

## Diagnostic Log Categories

All diagnostic log categories below MUST be enabled and forwarded to Log Analytics.

| Log Category | Description | OMB M-21-31 Tier | NIST Control |
|-------------|-------------|-------------------|--------------|
| AppServiceHTTPLogs | HTTP request/response logs (method, URL, status, latency, user agent) | EL2 | AU-2, AU-3, AU-12 |
| AppServiceConsoleLogs | Console output from the application (stdout/stderr) | EL2 | AU-2, AU-12 |
| AppServiceAppLogs | Application-level logs generated by the app framework | EL2 | AU-2, AU-12 |
| AppServiceAuditLogs | Audit logs for publishing and configuration changes | EL3 | AU-2, AU-3, AU-12 |
| AppServiceIPSecAuditLogs | IP security audit logs (IP restriction rule matches) | EL3 | AU-2, SC-7 |
| AppServicePlatformLogs | Platform-level logs (scaling events, health checks, container operations) | EL2 | AU-2, AU-12, SI-4 |
| AppServiceAntivirusScanAuditLogs | Antivirus scan results from Microsoft Defender | EL3 | AU-2, SI-3 |

### Metrics

| Metric Category | Description | OMB M-21-31 Tier | NIST Control |
|----------------|-------------|-------------------|--------------|
| AllMetrics | CPU, memory, requests, response time, connections | EL1 | SI-4 |

## Retention

| Tier | Retention Period | Justification |
|------|-----------------|---------------|
| Hot (Log Analytics) | 90 days (production) / 30 days (lower) | Active query and alerting |
| Archive (Storage Account) | 548 days (production) | FedRAMP AU-11 audit record retention |

## Alert Rules

The following alerts MUST be configured in the shared monitoring infrastructure:

| Alert Name | Condition | Severity | Action Group | NIST Control |
|-----------|-----------|----------|-------------|--------------|
| HTTP 5xx Spike | AppServiceHTTPLogs where ScStatus >= 500 count > 10 in 5 minutes | Sev 1 (Error) | SOC + App Team | SI-4, AU-6 |
| Failed Authentication | AppServiceAuditLogs where authentication failure detected | Sev 1 (Error) | SOC + Incident Response | IA-2, SI-4 |
| Deployment Event | AppServiceAuditLogs where operation == "publish" | Sev 3 (Informational) | App Team | CM-3, AU-12 |
| Antivirus Detection | AppServiceAntivirusScanAuditLogs where threat detected | Sev 1 (Error) | SOC + Incident Response | SI-3 |
| IP Restriction Violation | AppServiceIPSecAuditLogs where action == "Denied" count > 5 in 5 minutes | Sev 2 (Warning) | SOC | SC-7, SI-4 |
| High Response Time | AllMetrics where AverageResponseTime > 5000ms for 10 minutes | Sev 2 (Warning) | App Team | SI-4 |

## Log Query Examples

### HTTP 5xx Error Spike
```kusto
AppServiceHTTPLogs
| where ScStatus >= 500
| summarize ErrorCount = count() by CsHost, ScStatus, bin(TimeGenerated, 5m)
| where ErrorCount > 10
| order by ErrorCount desc
```

### Failed Authentication Attempts
```kusto
AppServiceAuditLogs
| where Category == "AppServiceAuditLogs"
| where Properties has "401" or Properties has "403"
| summarize FailedCount = count() by _ResourceId, bin(TimeGenerated, 5m)
| where FailedCount > 5
| order by FailedCount desc
```

### Publishing/Deployment Events
```kusto
AppServiceAuditLogs
| where OperationName has "publish" or OperationName has "deploy"
| project TimeGenerated, _ResourceId, OperationName, Properties
| order by TimeGenerated desc
```

### Antivirus Scan Results
```kusto
AppServiceAntivirusScanAuditLogs
| where Category == "AppServiceAntivirusScanAuditLogs"
| project TimeGenerated, _ResourceId, Properties
| order by TimeGenerated desc
```

### Denied IP Restriction Requests
```kusto
AppServiceIPSecAuditLogs
| where CsHost != ""
| summarize DeniedCount = count() by CIp, CsHost, bin(TimeGenerated, 5m)
| where DeniedCount > 5
| order by DeniedCount desc
```
